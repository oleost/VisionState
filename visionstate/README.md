# VisionState

Teach a local AI what your camera sees — garage door open, closed or halfway, gate shut — and
use it as a Home Assistant sensor. Find people, cars and animals without any training, or read the
number on a power, water or gas meter. Runs 100 % locally on any CPU.

![VisionState dashboard](https://raw.githubusercontent.com/oleost/VisionState/main/docs/promo/dashboard.png)

See the **Documentation** tab for how to use it.
